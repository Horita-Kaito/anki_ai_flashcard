# Tessera ロゴ制作依頼書

本書は、外部デザイナーへ **Tessera** のロゴ制作を依頼するための要件書である。

UI 全体のデザイン依頼ではなく、今回は **ロゴのみ** を対象とする。

## 依頼内容

正式名称 **Tessera** のブランドロゴを制作してほしい。

必要なもの:

- アプリアイコンとして使えるシンボルマーク
- 横組みロゴ
- 縦組みまたはコンパクト配置のロゴ
- 単色版
- 小サイズ表示に耐える簡略版

## プロダクト概要

Tessera は、AI 策問補助付きのフラッシュカードアプリである。

ユーザーは学習中のメモや間違えた論点を入力する。AI はそのメモからフラッシュカード候補を生成する。ユーザーは候補をレビューし、必要なものだけを採用する。採用したカードは間隔反復で復習する。

目的は、AI で情報処理するだけで終わらせず、学習内容を記憶として定着させること。

中心体験:

**メモを書く → AI が候補を出す → 人間がレビューして採用する → 復習で記憶に定着させる**

## アプリ名

正式名称: **Tessera**

名称意図:

- 「まな」: 学び、やさしさ、親しみやすさ
- 「メモ」: 学習素材を気軽に残す行為
- 「AI」: カード候補生成を助ける知的な補助機能

ロゴでは、名前の軽さと親しみやすさを活かしたい。ただし、子供向け教材に寄りすぎず、大人の資格学習や技術学習でも使える信頼感を持たせたい。

## ターゲット印象

目指す印象:

- 子供にも親しみやすい
- 大人にも信頼される
- 学習が続きそう
- やさしい
- 落ち着いている
- 書物や紙の手触りがある
- AI が自然に手伝ってくれる

避けたい印象:

- 近未来的すぎる AI SaaS
- ネオン、グラデーション過多、サイバー感
- 子供向けキャラクターに寄りすぎる
- 図書館 / 電子書籍 / 読書アプリに見える
- 塾や学校教材のように硬すぎる
- 星やスパークだけで AI 感を表す
- 純白 / 純黒の強すぎるコントラスト

## 世界観

アプリ全体は、書物風のデザインになる予定。

キーワード:

- 紙
- メモ
- 問い
- 記憶
- 復習
- しおり
- 罫線
- 余白
- 静かな集中
- 小さなひらめき
- やさしい AI

ロゴは「本そのもの」を強く描きすぎる必要はない。書物風 UI に馴染むことが重要であり、読書アプリに見えることは避けたい。

## ロゴで表現したいこと

優先度が高いもの:

- メモが学びに変わる
- メモが問いに変わる
- 学びが記憶として残る
- AI は主役ではなく、そっと手伝う存在
- 毎日少しずつ続ける学習

優先度が低いもの:

- 本格的な読書
- 学校らしさ
- テストの緊張感
- AI の技術感そのもの
- フラッシュカードの機械的な反復感

## 検討してほしい方向性

### 方向 A: 「ま」の文字を記号化

日本語ブランドとして覚えやすく、アプリアイコンにも展開しやすい。

期待:

- 親しみやすい
- 小サイズでも識別しやすい
- Tessera の名前と結びつきやすい

注意:

- 筆文字や和風に寄せすぎない
- 子供っぽい丸文字にしすぎない

### 方向 B: メモが問いに変わる瞬間

メモ、カード、問い、AI 補助を抽象化する方向。

期待:

- プロダクト独自性が出る
- AI 策問補助の価値が伝わる
- 読書アプリに見えにくい

注意:

- クエスチョンマークを直球で使いすぎない
- 星やスパークだけに頼らない

### 方向 C: 紙片 / カード / しおりの抽象化

書物風 UI に馴染ませつつ、重すぎない学習感を作る方向。

期待:

- 書物風パレットと相性がよい
- 大人にも受け入れやすい
- アプリアイコンにしやすい

注意:

- 本そのものを描きすぎると読書アプリに見える
- 線が太すぎると教材感が強くなる

### 方向 D: キャラクター未満の相棒感

顔や表情を最小限にした、親しみのある記号。

期待:

- 子供にも親しみやすい
- AI がそっと手伝う感じを出しやすい
- 将来的なオンボーディングや空状態にも展開しやすい

注意:

- マスコット化しすぎない
- 幼児向けに見えないようにする

## 避けたい具体表現

- 開いた本をそのまま大きく描く
- AI を星マークだけで表す
- ロボットの顔を前面に出す
- 脳、電球、卒業帽などの汎用学習アイコンに寄せる
- ネオンブルー、紫グラデーション、サイバーな回路
- 純白背景に純黒文字
- 教科書、学校、塾のような硬い見え方

## 判断基準

採用時に見るポイント:

- 「Tessera」という名前に合っている
- 子供にも親しみやすい
- 大人の資格学習にも耐える
- 書物風カラーパレットと合う
- AI 感があるが主張しすぎない
- メモ、問い、記憶、復習のいずれかが自然に想起できる
- 小サイズでも崩れない
- 横組みでもアプリアイコンでも成立する
- 他の学習アプリや読書アプリと見分けがつく

## 補足

今回は UI 全体のデザインではなく、ロゴ制作のみを依頼する。

ただし、ロゴは将来的な UI 全体のトーンを決める起点になる。書物風、暖かい紙、落ち着いた深緑、控えめな AI 感という方向性は意識してほしい。
