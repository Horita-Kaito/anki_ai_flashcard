# UI/UX 全面刷新 実装記録 (2026-07)

`docs/11_design_redesign_brief.md` を受けて実施した全面リデザインの、実装ベースの設計判断記録。ブランチ: `feature/ux-redesign`。

## 体験コンセプト

**「今日やることが、開いた瞬間にわかる作業台」**

中心ループ (メモを書く → AI が候補を出す → 人間が採用する → 復習で思い出す) を、初見ユーザーでも説明なしに一周できることを最優先にした。

## 設計判断と根拠

### 1. デザイン基盤

- **ダークテーマの実装**: これまで `.dark` クラスは切り替わるのにトークン定義が無かった。`globals.css` に warm dark (夜の学習を想定した低彩度・暖色トーン) の全トークン (`--forest` / `--bronze` / `--persimmon` 系ブランドパレット含む) と `color-scheme` を定義した。
- **共通プリミティブの新設** (`shared/ui`): `Card` / `Input` / `Textarea` / `NativeSelect` / `Label` / `Badge` / `EmptyState` / `ErrorState`。従来は素の `<input>` + インライン Tailwind が画面ごとに散っていた。フォーム系は SP で 44px タップターゲット + 16px フォント (iOS ズーム防止)、PC でコンパクトという分岐をプリミティブ側に封じた。
- **空状態の原則**: `EmptyState` は必ず「次の一歩」の CTA を持つ。「何もない」ではなく「次に何をすればいいか」を伝える。

### 2. オンボーディング (3 ステップウィザード)

初回ユーザーが最初に価値を感じる瞬間を「最初のメモから AI 候補が生まれる瞬間」と定義し、そこへ最短で導く。

1. **ようこそ** — 4 ステップの仕組み図解 + 信頼メッセージ「AI 候補は自動でカードにならない。採用するのはあなた」
2. **学習目的** — 従来のゴール選択 (複数可) を維持。ここで API 送信
3. **最初のメモ** — メモの実例 3 件を見せ、「最初のメモを書く」を primary CTA に。スキップ導線も残す

目的送信後に onboarding ステータスが completed になっても、ウィザード途中で dashboard へ強制リダイレクトされないよう「初回ロード時点の完了状態」だけをガードに使う。

### 3. ダッシュボード

- 最上段は **今日の復習ヒーロー** (期日枚数 + 開始 CTA)。期日 0 件時は「完了」or「まだ予定なし → メモを書く」の文脈別メッセージに切り替え、行き止まりを作らない。
- **承認待ち AI 候補コールアウト** は >0 件のときだけ persimmon トーンで出す。「採用したカードだけが復習に出る」という製品ルールを都度言語化する。
- **はじめの 3 ステップ チェックリスト** (新規ユーザー向け): ①メモを書く ②候補を採用 ③今日の復習。dashboard summary から完了判定 (メモ有無 / total_cards / streak.today_done)。全達成で自動消滅、× で dismiss (localStorage)。オンボーディング離脱後のリカバリー導線でもある。
- AI 使用量・コストは折りたたみへ後退 (表示は維持、主役にしない)。

### 4. ナビゲーション

- PC サイドバー: 学習/整理/運用の 3 グループ維持。アクティブは `--forest-faint` の pill。**最下部にユーザーセクション** (名前・テーマ切替・ログアウト) を恒常化 — 従来ログアウトがダッシュボードにしかなかった問題の解消。
- SP: 4 タブ +「その他」構成維持。「その他」にテーマ切替・ログアウトを追加。ナビ定義は `widgets/app-shell/nav-config.ts` に一元化。

### 5. 主要フロー画面

- **メモ入力**: 本文 textarea を主役に、詳細設定 (テンプレート/サブ分野/学習目的/補足) は折りたたみ。SP はアクション下部固定 + safe-area。「保存して候補生成」が primary。
- **候補レビュー**: 問題文を主役、confidence / focus type / AI 判断理由はメタ情報として控えめに。採用が primary で SP では親指が届く位置。採用済み/却下済みは Badge で状態明示。一括採用バーは sticky bottom。
- **復習**: カード集中モード。ヘッダーは細い進捗バーのみ。SP は評価 4 ボタンを下部固定 (Again=persimmon / Hard=bronze / Good=forest / Easy=primary)、PC は中央横並び + `<kbd>` ヒント。完了画面は軽い称賛 + 次の一歩 CTA。
- **LP**: 「読んだだけで、終わらせない。」を軸に、要約アプリではなく記憶定着アプリであることを 4 ステップフローと信頼メッセージで伝える。

キーボードショートカット (Space/Enter, 1-4, Cmd/Ctrl+Enter, ⌘K)、スワイプ評価、ハプティクス、Undo toast、連続メモ作成、生成ポーリング/partial success 表示、デッキ集中モード、admin ガード、44px タップターゲット、focus-visible、TanStack Query hook と API 契約のすべて。
